Title : Database Administrator
Job Summary:
DBA/Database Administrator is responsible to manage and maintain the SQL Server and Oracle Database systems supporting multiple critical company systems. As a DBA, you are responsible to design, install, monitor, maintain, and performance tuning of production databases while ensuring high levels of data availability. DBA, also Develops, implements, and oversees database policies and procedures to ensure the integrity and availability of databases and their accompanying software. DBA should be able to technically lead/coordinate projects related to the Database systems and keep the Database up and running smoothly 24/7. The goal of DBA is ensure performance, integrity and security of Databases, which could include confidential Company’s financial data. As a DBA, he/she needs to make sure that data is available to users and secure from unauthorized access or accidental loss or corruption.
Job Duties:
•	SQL Server 2012/2014/2016/2019 Database administration, configuration, troubleshooting, Performance tuning & Query Optimization, Replication, Log Shipping & clustering.
•	Oracle 11g/12c Database administration, configuration, troubleshooting, Performance tuning and Query Optimization advanced replication, Golden gate, DataGaurd.
•	Manage database engines of Oracle, SQL Server, and MySQL on AWS.
•	Work on Implement High Availability solutions for SQL Server & Oracle databases like Log shipping, replication, Clustering, Mirroring, Multi-Master/Transactional Replication. 
•	Perform applications database administration (Oracle) services including SQL code review, performance analysis, Query Tuning, database application design, physical data modeling, development support & Engineering.
•	Advanced Working knowledge and experience on Creating and deploying SSIS Packages, SSRS reports and SQL Server High Availability Solutions knowledge is critical.
•	Ensure all Database Backups are reliable & restorable as per RTO & RPO.
•	Responsible for proposing and validating approved disaster recovery and business continuance solutions for Oracle and SQL Server Databases.
•	Ensure Dev,Test are Synced with Production environments and Perform Regular Health Checks on the Database Servers & Proactively monitor databases servers , Setup and respond to any alerts.
•	Define thresholds on Performance Counters for monitoring tools like Nagios, Solar winds.
•	Working with RMAN for backup, recovery and duplicate Oracle databases, Use DB Flashback feature to restore database/DB tables.
•	Create User accounts, Roles and granting required access, permissions and privileges to the Database based on the Principle of least Privileges.
•	Schedule & Perform regular DB maintenance Like Index Maintenance, Statistics update, Applying Security packs, cumulative packs for SQL Servers & Upgrading Oracle Databases.
•	Establish database standards for operations, upgrades, migrations and Write clear, concise, well-organized user documentation to maintain standards and procedures.
•	Participate in 24/7 on call rotation schedule for various production support, database maintenance, housekeeping and installs
•	Responsible for the establishment of KPIs for the Database service and implementing metric-driven improvement objectives on time and within budget.
•	Responsible for the evaluation of Database software purchases and work closely with IT project managers, Database programmers and multimedia programmers.
